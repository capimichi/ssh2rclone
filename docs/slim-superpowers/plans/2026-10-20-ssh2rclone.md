# ssh2rclone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a Go CLI tool (`ssh2rclone`) that converts `~/.ssh/config` entries into idempotent SFTP remotes inside `rclone.conf` delimited by dedicated tags, preserving manual configs and skipping duplicates.

**Architecture:** Layered architecture under `internal/`: pure domain models in `internal/model`, generic utilities in `internal/helper`, path discovery (CLI/env/rclone binary/XDG) in `internal/config`, and core business logic in `internal/services` (`ssh_parser.go` for OpenSSH parsing/inheritance and `rclone_sync.go` for tag demarcation, conflict skipping, and atomic sync).

**Tech Stack:** Go 1.25, `github.com/kevinburke/ssh_config`, Go Standard Library (`os`, `path/filepath`, `bufio`, `strings`, `flag`, `os/exec`).

## Global Constraints

- Module name: `github.com/michele/ssh2rclone` (or `ssh2rclone`).
- Delimiter tags: `# --- BEGIN ssh2rclone GENERATED BLOCK (DO NOT EDIT MANUALLY) ---` and `# --- END ssh2rclone GENERATED BLOCK ---`.
- Strict isolation: never touch, alter, or remove any content outside the delimiter tags.
- Conflict policy: if an SSH alias matches a section name outside the delimiters, log a `[WARN]` and skip that remote.
- Safety: atomic file writes via temporary file and `os.Rename`, automatic `.bak` copy prior to writes (unless `--no-backup` is set).
- Simple vs Complex: if `ProxyJump != ""` or `ProxyCommand != ""` or `--all-ssh`, use `ssh = ssh <alias>`; otherwise map `host`, `user`, `port`, `key_file`.

package config

import (
	"bytes"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
)

// ExpandHome replaces a leading "~" or "~/" with the user's home directory.
func ExpandHome(path string) (string, error) {
	if path == "" {
		return "", nil
	}
	if path == "~" {
		return os.UserHomeDir()
	}
	if strings.HasPrefix(path, "~/") {
		home, err := os.UserHomeDir()
		if err != nil {
			return "", err
		}
		return filepath.Join(home, path[2:]), nil
	}
	return path, nil
}

// ResolveSSHConfigPath returns the path to the SSH config file.
func ResolveSSHConfigPath(cliPath string) (string, error) {
	if cliPath != "" {
		return ExpandHome(cliPath)
	}
	return ExpandHome("~/.ssh/config")
}

// ResolveRcloneConfigPath determines the rclone.conf location using:
// 1. CLI flag
// 2. RCLONE_CONFIG env var
// 3. `rclone config file` command if rclone is in $PATH
// 4. XDG_CONFIG_HOME or ~/.config/rclone/rclone.conf (with legacy ~/.rclone.conf check).
func ResolveRcloneConfigPath(cliPath string) (string, error) {
	if cliPath != "" {
		return ExpandHome(cliPath)
	}

	if envPath := os.Getenv("RCLONE_CONFIG"); envPath != "" {
		return ExpandHome(envPath)
	}

	// Try querying rclone binary directly if installed
	if rcloneBin, err := exec.LookPath("rclone"); err == nil && rcloneBin != "" {
		cmd := exec.Command("rclone", "config", "file")
		var out bytes.Buffer
		cmd.Stdout = &out
		if err := cmd.Run(); err == nil {
			lines := strings.Split(out.String(), "\n")
			for _, line := range lines {
				trimmed := strings.TrimSpace(line)
				if strings.HasSuffix(trimmed, "rclone.conf") {
					return trimmed, nil
				}
			}
		}
	}

	// Check legacy ~/.rclone.conf
	home, err := os.UserHomeDir()
	if err == nil {
		legacy := filepath.Join(home, ".rclone.conf")
		if _, err := os.Stat(legacy); err == nil {
			return legacy, nil
		}
	}

	// XDG standard location
	if xdg := os.Getenv("XDG_CONFIG_HOME"); xdg != "" {
		return filepath.Join(xdg, "rclone", "rclone.conf"), nil
	}

	if home != "" {
		return filepath.Join(home, ".config", "rclone", "rclone.conf"), nil
	}

	return "", fmt.Errorf("unable to determine rclone config path")
}
```

package helper

import (
	"fmt"
	"io"
	"os"
	"path/filepath"
)

// AtomicWriteFile safely writes data to target path by writing to a temporary file
// in the same directory and renaming it over the destination.
func AtomicWriteFile(destPath string, data []byte, perm os.FileMode) error {
	dir := filepath.Dir(destPath)
	if err := os.MkdirAll(dir, 0755); err != nil {
		return fmt.Errorf("failed to create directory %s: %w", dir, err)
	}

	tmpFile, err := os.CreateTemp(dir, "ssh2rclone-tmp-*.conf")
	if err != nil {
		return fmt.Errorf("failed to create temp file in %s: %w", dir, err)
	}
	tmpName := tmpFile.Name()

	defer func() {
		// Clean up temp file if rename didn't happen
		_ = os.Remove(tmpName)
	}()

	if _, err := tmpFile.Write(data); err != nil {
		_ = tmpFile.Close()
		return fmt.Errorf("failed to write data to temp file: %w", err)
	}

	if err := tmpFile.Chmod(perm); err != nil {
		_ = tmpFile.Close()
		return fmt.Errorf("failed to chmod temp file: %w", err)
	}

	if err := tmpFile.Close(); err != nil {
		return fmt.Errorf("failed to close temp file: %w", err)
	}

	if err := os.Rename(tmpName, destPath); err != nil {
		return fmt.Errorf("failed to rename %s to %s: %w", tmpName, destPath, err)
	}

	return nil
}

// CreateBackup copies destPath to destPath.bak if destPath exists.
func CreateBackup(destPath string) (string, error) {
	if _, err := os.Stat(destPath); os.IsNotExist(err) {
		return "", nil // Nothing to back up
	}

	bakPath := destPath + ".bak"
	src, err := os.Open(destPath)
	if err != nil {
		return "", fmt.Errorf("failed to open source for backup: %w", err)
	}
	defer src.Close()

	info, err := src.Stat()
	if err != nil {
		return "", fmt.Errorf("failed to stat source: %w", err)
	}

	dst, err := os.OpenFile(bakPath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, info.Mode())
	if err != nil {
		return "", fmt.Errorf("failed to create backup file: %w", err)
	}
	defer dst.Close()

	if _, err := io.Copy(dst, src); err != nil {
		return "", fmt.Errorf("failed to copy data to backup: %w", err)
	}

	return bakPath, nil
}
```

package services

import (
	"fmt"
	"os"
	"strings"

	"github.com/kevinburke/ssh_config"
	"ssh2rclone/internal/config"
	"ssh2rclone/internal/model"
)

// isWildcard checks if an alias contains pattern matching characters.
func isWildcard(alias string) bool {
	return strings.ContainsAny(alias, "*?")
}

// ParseSSHConfig reads an SSH config file and extracts concrete SSHEntry records.
func ParseSSHConfig(filePath string, opts model.SyncOptions) ([]model.SSHEntry, error) {
	f, err := os.Open(filePath)
	if err != nil {
		return nil, fmt.Errorf("failed to open ssh config at %s: %w", filePath, err)
	}
	defer f.Close()

	cfg, err := ssh_config.Decode(f)
	if err != nil {
		return nil, fmt.Errorf("failed to decode ssh config: %w", err)
	}

	var entries []model.SSHEntry
	seen := make(map[string]bool)

	for _, host := range cfg.Hosts {
		for _, pattern := range host.Patterns {
			alias := pattern.String()
			if isWildcard(alias) || seen[alias] {
				continue
			}
			seen[alias] = true

			// Query resolved properties through ssh_config
			hostname, _ := cfg.Get(alias, "HostName")
			if hostname == "" {
				hostname = alias
			}

			user, _ := cfg.Get(alias, "User")
			port, _ := cfg.Get(alias, "Port")
			if port == "" {
				port = "22"
			}

			keyFile, _ := cfg.Get(alias, "IdentityFile")
			if keyFile != "" {
				expanded, err := config.ExpandHome(keyFile)
				if err == nil {
					keyFile = expanded
				}
			}

			proxyJump, _ := cfg.Get(alias, "ProxyJump")
			proxyCommand, _ := cfg.Get(alias, "ProxyCommand")

			isComplex := opts.AllSSH || proxyJump != "" || proxyCommand != ""

			entries = append(entries, model.SSHEntry{
				Alias:        alias,
				HostName:     hostname,
				User:         user,
				Port:         port,
				KeyFile:      keyFile,
				ProxyJump:    proxyJump,
				ProxyCommand: proxyCommand,
				IsComplex:    isComplex,
			})
		}
	}

	return entries, nil
}
```

package services

import (
	"bufio"
	"fmt"
	"os"
	"regexp"
	"strings"

	"ssh2rclone/internal/helper"
	"ssh2rclone/internal/model"
)

const (
	BlockBeginTag = "# --- BEGIN ssh2rclone GENERATED BLOCK (DO NOT EDIT MANUALLY) ---"
	BlockEndTag   = "# --- END ssh2rclone GENERATED BLOCK ---"
)

var sectionRegex = regexp.MustCompile(`^\s*\[([^\]]+)\]\s*$`)

// SyncResult summarizes the synchronization operation.
type SyncResult struct {
	AddedRemotes     []string
	SkippedConflicts []string
	BackupPath       string
	RenderedBlock    string
}

// BuildRemotes converts SSHEntry models to RcloneRemote models.
func BuildRemotes(entries []model.SSHEntry) []model.RcloneRemote {
	var remotes []model.RcloneRemote
	for _, e := range entries {
		remote := model.RcloneRemote{
			Name: e.Alias,
			Type: "sftp",
		}
		if e.IsComplex {
			remote.SSHCommand = fmt.Sprintf("ssh %s", e.Alias)
		} else {
			remote.Host = e.HostName
			remote.User = e.User
			remote.Port = e.Port
			remote.KeyFile = e.KeyFile
		}
		remotes = append(remotes, remote)
	}
	return remotes
}

// RenderBlock formats a slice of RcloneRemote into the delimited block string.
func RenderBlock(remotes []model.RcloneRemote) string {
	var sb strings.Builder
	sb.WriteString(BlockBeginTag + "\n")
	for i, r := range remotes {
		sb.WriteString(fmt.Sprintf("[%s]\n", r.Name))
		sb.WriteString(fmt.Sprintf("type = %s\n", r.Type))
		if r.SSHCommand != "" {
			sb.WriteString(fmt.Sprintf("ssh = %s\n", r.SSHCommand))
		} else {
			if r.Host != "" {
				sb.WriteString(fmt.Sprintf("host = %s\n", r.Host))
			}
			if r.User != "" {
				sb.WriteString(fmt.Sprintf("user = %s\n", r.User))
			}
			if r.Port != "" {
				sb.WriteString(fmt.Sprintf("port = %s\n", r.Port))
			}
			if r.KeyFile != "" {
				sb.WriteString(fmt.Sprintf("key_file = %s\n", r.KeyFile))
			}
		}
		if i < len(remotes)-1 {
			sb.WriteString("\n")
		}
	}
	sb.WriteString(BlockEndTag + "\n")
	return sb.String()
}

// ExtractExternalSections parses rclone.conf content, separates prefix and suffix
// around any existing managed block, and collects section names defined outside the block.
func ExtractExternalSections(content string) (map[string]bool, string, string) {
	externalSections := make(map[string]bool)

	beginIdx := strings.Index(content, BlockBeginTag)
	endIdx := strings.Index(content, BlockEndTag)

	var prefix, suffix string
	if beginIdx != -1 && endIdx != -1 && endIdx > beginIdx {
		prefix = content[:beginIdx]
		suffix = content[endIdx+len(BlockEndTag):]
		// Clean up leading newline in suffix if present
		if strings.HasPrefix(suffix, "\n") {
			suffix = suffix[1:]
		}
	} else {
		prefix = content
		suffix = ""
	}

	scanner := bufio.NewScanner(strings.NewReader(prefix + "\n" + suffix))
	for scanner.Scan() {
		line := scanner.Text()
		matches := sectionRegex.FindStringSubmatch(line)
		if len(matches) == 2 {
			externalSections[matches[1]] = true
		}
	}

	return externalSections, prefix, suffix
}

// SyncRcloneConfig performs the synchronization following isolation and conflict policies.
func SyncRcloneConfig(entries []model.SSHEntry, opts model.SyncOptions) (SyncResult, error) {
	var result SyncResult

	var existingContent string
	if data, err := os.ReadFile(opts.RcloneConfigPath); err == nil {
		existingContent = string(data)
	}

	externalSections, prefix, suffix := ExtractExternalSections(existingContent)

	var validEntries []model.SSHEntry
	for _, entry := range entries {
		if externalSections[entry.Alias] {
			result.SkippedConflicts = append(result.SkippedConflicts, entry.Alias)
			if opts.Verbose {
				fmt.Printf("[WARN] Remote '%s' already exists in manual rclone config; skipping.\n", entry.Alias)
			}
			continue
		}
		validEntries = append(validEntries, entry)
		result.AddedRemotes = append(result.AddedRemotes, entry.Alias)
	}

	remotes := BuildRemotes(validEntries)
	result.RenderedBlock = RenderBlock(remotes)

	if opts.DryRun {
		return result, nil
	}

	// Create backup if file exists and backup not disabled
	if !opts.NoBackup && existingContent != "" {
		bakPath, err := helper.CreateBackup(opts.RcloneConfigPath)
		if err != nil {
			return result, fmt.Errorf("failed to create backup: %w", err)
		}
		result.BackupPath = bakPath
	}

	// Assemble final content
	var finalContent strings.Builder
	trimmedPrefix := strings.TrimRight(prefix, "\r\n")
	if trimmedPrefix != "" {
		finalContent.WriteString(trimmedPrefix)
		finalContent.WriteString("\n\n")
	}

	finalContent.WriteString(result.RenderedBlock)

	trimmedSuffix := strings.TrimLeft(suffix, "\r\n")
	if trimmedSuffix != "" {
		finalContent.WriteString("\n")
		finalContent.WriteString(trimmedSuffix)
	}

	if err := helper.AtomicWriteFile(opts.RcloneConfigPath, []byte(finalContent.String()), 0600); err != nil {
		return result, fmt.Errorf("failed writing rclone config: %w", err)
	}

	return result, nil
}

		os.Exit(1)

	rclonePath, err := config.ResolveRcloneConfigPath(opts.RcloneConfigPath)
	if err != nil {
		fmt.Fprintf(os.Stderr, "Error resolving rclone config path: %v\n", err)
		os.Exit(1)
	}
	opts.RcloneConfigPath = rclonePath

	if opts.Verbose {
		fmt.Printf("Using SSH config: %s\n", opts.SSHConfigPath)
		fmt.Printf("Using rclone config: %s\n", opts.RcloneConfigPath)
	}

	// Parse SSH config
	entries, err := services.ParseSSHConfig(opts.SSHConfigPath, opts)
	if err != nil {
		fmt.Fprintf(os.Stderr, "Error parsing SSH config: %v\n", err)
		os.Exit(1)
	}

		fmt.Printf("Discovered %d concrete host(s) in SSH config\n", len(entries))

	res, err := services.SyncRcloneConfig(entries, opts)
	if err != nil {
		fmt.Fprintf(os.Stderr, "Error updating rclone config: %v\n", err)
		os.Exit(1)

	}

# ssh2rclone

Convert SSH configurations (`~/.ssh/config`) to `rclone` remote definitions (`rclone.conf`) safely and idempotently.

## Features

- **Idempotent Updates:** Encloses generated remotes within dedicated delimiters (`# --- BEGIN ssh2rclone ... # --- END ssh2rclone`). Rerunning cleanly updates the block.
- **Strict Isolation:** Never modifies or deletes any remote defined manually outside the delimiter block.
- **Conflict Prevention:** Skips any SSH host with a warning if a manual remote with the same name already exists outside the block.
- **Smart Delegation:**
  - Standard hosts: converted to native rclone SFTP remotes (`host`, `user`, `port`, `key_file`).
  - Jump/Proxy hosts: automatically configured to delegate to OpenSSH (`ssh = ssh <alias>`), inheriting `ProxyJump`, `ProxyCommand`, and agent keys.
- **Automatic Path Discovery:** Detects `rclone.conf` through CLI flag, `$RCLONE_CONFIG`, `rclone config file`, or XDG standard paths.
- **Safe Operations:** Atomic file writes (temp file + rename) and automatic backup (`rclone.conf.bak`).

## Installation

```bash
go build -o ssh2rclone main.go
# or install to $GOPATH/bin
go install
```

## Usage

```bash
# Synchronize default ~/.ssh/config to detected rclone.conf
ssh2rclone

# Preview changes without writing to disk
ssh2rclone --dry-run

# Force all hosts to delegate through OpenSSH client
ssh2rclone --all-ssh

# Custom config paths
ssh2rclone --ssh-config /path/to/ssh_config --rclone-config /path/to/rclone.conf

# Disable automatic .bak backup
ssh2rclone --no-backup

# Verbose logging
ssh2rclone -v
```
